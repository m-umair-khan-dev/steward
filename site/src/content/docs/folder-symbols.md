---
title: Folder symbols and colours
description: Folders show what is inside them.
order: 9
section: Everyday
---

Cairn picks a symbol for each folder: special folders get theirs (Downloads, Pictures…), code projects get the code symbol, a folder called *Invoices* gets a receipt, and a folder that is mostly PDFs gets the PDF symbol.

To choose your own, right-click the folder and pick **Symbol and Colour…**. Your choice is stored with the folder, so it survives renames and moves. *Automatic* goes back to Cairn's choice.

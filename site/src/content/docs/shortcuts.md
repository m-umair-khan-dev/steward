---
title: Keyboard shortcuts
description: Every key Steward uses.
order: 17
section: Reference
---

| Key | Does |
|---|---|
| <kbd>Ctrl+K</kbd> | Find anything |
| <kbd>Ctrl+L</kbd> | Type a path or a folder name |
| <kbd>Ctrl+F</kbd> | Filter this folder |
| <kbd>Space</kbd> | Peek |
| <kbd>F2</kbd> | Rename |
| <kbd>Delete</kbd> | Move to the Trash |
| <kbd>Ctrl+Z</kbd> / <kbd>Ctrl+Shift+Z</kbd> | Undo / Redo |
| <kbd>Ctrl+Shift+N</kbd> | New folder |
| <kbd>Ctrl+Shift+O</kbd> | Tidy this folder |
| <kbd>F3</kbd> | Two panes |
| <kbd>Tab</kbd> | Switch pane |
| <kbd>F5</kbd> / <kbd>F6</kbd> | Copy / move to the other pane |
| <kbd>Ctrl+U</kbd> | Swap the panes |
| <kbd>Alt+1</kbd> … <kbd>Alt+9</kbd> | Open a workspace |
| <kbd>Ctrl+Shift+K</kbd> | Free Up Space |
| <kbd>Ctrl+1</kbd> / <kbd>Ctrl+2</kbd> | Grid / list |
| <kbd>Ctrl++</kbd> / <kbd>Ctrl+-</kbd> / <kbd>Ctrl+0</kbd> | Larger / smaller / normal size |
| <kbd>Ctrl+H</kbd> | Hidden files |
| <kbd>F9</kbd> | Collapse the sidebar |
| <kbd>Ctrl+Shift+P</kbd> | Preview pane |
| <kbd>Alt+←</kbd> / <kbd>Alt+→</kbd> / <kbd>Alt+↑</kbd> | Back / forward / up |
| <kbd>Ctrl+,</kbd> | Preferences |
| <kbd>Ctrl+?</kbd> | This list, in the app |
| <kbd>Ctrl+Q</kbd> | Quit |

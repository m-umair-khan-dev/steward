---
title: Tidy and Smart Downloads
description: Sort loose files into kind folders, with a plan first and one Undo.
order: 10
section: Tools
---

In any folder, press <kbd>Ctrl+Shift+O</kbd>. Steward shows the plan: which files go into which kind folder (Images, PDFs, Documents…), and which stay where they are and why — still downloading, or added less than two minutes ago. Folders are never moved.

Press **Tidy** to do it. One <kbd>Ctrl+Z</kbd> puts every file back and removes the folders Tidy made. If a kind folder already holds a file with the same name, both are kept.

In **Downloads**, the preview pane also shows what takes the space and suggests what could go: installers for apps you already have, likely duplicates, and files nobody has opened for 90 days. *Move to Trash* on a suggestion is one step with Undo. Choose which folder counts as Downloads in Preferences.

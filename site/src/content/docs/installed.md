**Installed** lists packages from apt, Snap, Flatpak, npm, pipx, pip, Cargo, Go, RubyGems and Homebrew in one place, with their sizes. Tools you do not have are simply not shown.

Each package says why it is there: an *app*, something *you installed*, or something that *came with others*. Filter by those, or by tool. The copy button next to a package copies the command that would remove it; Steward never runs it. **Save List…** writes the whole list to a text file.
